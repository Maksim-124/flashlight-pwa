# 🎮 Multi-Theme Flashlight PWA

PWA-фонарик с несколькими темами оформления. Превращает экран вашего устройства в источник света с различными визуальными стилями.

**Ссылка на приложение**: https://maksim-124.github.io/flashlight-pwa/

## ✨ Возможности

- **Несколько тем**: Переключайтесь между разными визуальными темами
  - **Grid Theme**: Современный киберпанк стиль
  - **Warhammer Theme**: Индустриальный имперский стиль
- **Регулировка яркости**: Контролируйте интенсивность света от 10% до 100%
- **Поддержка жестов**: Свайп влево/вправо для регулировки яркости
- **Горячие клавиши**: Пробел для включения/выключения
- **PWA**: Установка на мобильные устройства и компьютеры
- **Оффлайн работа**: Работает без интернета
- **Адаптивный дизайн**: Оптимизирован для всех размеров экранов

## 🚀 Быстрый старт

### Онлайн версия (Рекомендуется)
1. Перейдите по ссылке: https://maksim-124.github.io/flashlight-pwa/
2. Нажмите "Добавить на главный экран" в меню браузера
3. Готово!

### Локальная версия
```bash
# Клонируйте репозиторий
git clone https://github.com/Maksim-124/flashlight-pwa.git

# Перейдите в папку проекта
cd flashlight-pwa

# Запустите локальный сервер
python -m http.server 8000

 Откройте http://localhost:8000 в браузере.
